==========================

Chehak

Module:
Monocular Metric Depth Estimation

MODEL

IMPORTANT NOTE
--------------

Although the metric VKITTI model produces depth predictions
in metric units, the predictions are not ground-truth measurements.

For high-accuracy reconstruction, the predicted depth should
be evaluated and, if necessary, aligned/calibrated against
the available LiDAR data.

LiDAR can therefore be used to evaluate the depth predictions
using metrics such as MAE, RMSE and Absolute Relative Error.


HANDOFF TO RECONSTRUCTION
-------------------------

For each frame, the reconstruction module should load:

1. RGB image
2. Corresponding depth .npy file
3. Camera intrinsic matrix P3x3
4. Camera-to-world pose T4x4

The frame ID must remain consistent between the RGB image,
metadata and depth map.

Example:

Frame ID:
0000

Depth:
0000_depth.npy
